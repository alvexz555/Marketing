# ON RED | Marketing Media Library

Biblioteca pública de mídia e metadados para divulgação do jogo ON RED, da A.RISE.

## Estrutura

- `PT/`: artes da campanha em português.
- `EN/`: artes da campanha em inglês.
- `EVERGREEN/`: peças evergreen para reutilização.
- `catalogo.csv`: índice de mídia e campos para preparação de publicações.

## Convenções

- Não colocar código-fonte do jogo neste repositório.
- Manter os arquivos originais, sem recompressão ou alteração não aprovada.
- Usar nomes estáveis e sequenciais para as artes.
- Os links de mídia devem apontar para os arquivos públicos no GitHub (preferencialmente URLs `raw.githubusercontent.com`).
- A biblioteca é um estoque circular: variar as peças e reaproveitá-las após intervalo, com chamadas/legendas adequadas.

## Estado da preparação

Estrutura inicial criada. Os arquivos de imagem e os links diretos serão adicionados após a transferência dos binários para este repositório. O CSV só deve ser considerado pronto para importação depois que cada linha tiver URL pública válida e os campos específicos da plataforma forem revisados.

## Plataformas

Instagram, TikTok, YouTube Shorts e Pinterest. Formatos estáticos não substituem vídeos exigidos por TikTok e YouTube Shorts.
